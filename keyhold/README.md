# 메이플 키 누름 알림 (Windows 프로그램)

메이플스토리는 키를 계속 누르고 있어도 **약 1분 10초(10젠 정도, 1젠 ≈ 7.5초)** 가 지나면 공격이 나가지 않습니다.
이 프로그램은 키를 누르고 있는 시간을 재다가, **70초**가 되면 "삐-삐-삐" 알림음을 울립니다. 손을 뗐다가 다시 누르면 시간이 처음부터 다시 잽니다.

웹 브라우저가 아니라 PC에서 바로 실행하는 작은 창 프로그램이고, 메이플 타이머(웹)와는 따로 동작합니다.

## 게임은 건드리지 않습니다

- 0.015초마다 Windows에 **"지금 이 키가 눌려 있나?"** 만 물어봅니다(`GetAsyncKeyState`). 키보드 표시 프로그램과 같은 방식입니다.
- 메이플스토리 프로세스를 열거나, 메모리를 읽거나, 창을 찾지 않습니다.
- 키를 대신 누르거나(입력 보내기), 키 입력을 가로채지(키보드 훅) 않습니다.
- 누른 키를 기록하거나 어디로 보내지 않습니다. 저장하는 것은 설정값뿐입니다(`%APPDATA%\MapleKeyHoldAlarm\settings.ini`).
- 소스는 `KeyHoldAlarm.cs` 파일 하나이니 직접 확인할 수 있습니다.

## 실행하기

### 방법 1: 직접 빌드 (권장, 설치할 것 없음)

1. 이 `keyhold` 폴더를 PC에 받습니다(저장소 zip을 받아 압축 풀기).
2. `build.bat` 을 두 번 누릅니다. Windows에 기본으로 들어 있는 C# 컴파일러로 몇 초 만에 `KeyHoldAlarm.exe` 를 만듭니다.
   `[OK] KeyHoldAlarm.exe created.` 가 나오면 아무 키나 눌러 창을 닫습니다.
3. `KeyHoldAlarm.exe` 를 두 번 누릅니다.

### 방법 2: 들어 있는 exe 바로 실행

폴더에 미리 빌드한 `KeyHoldAlarm.exe` 가 들어 있습니다. 실행이 안 되면 방법 1로 빌드하세요.

> 인터넷에서 받은 파일이라 **"Windows의 PC 보호"** 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다.

## 쓰는 법

1. 프로그램을 켜 둔 채로 메이플을 합니다. 창은 기본으로 **항상 위**에 떠 있습니다(체크 해제 가능).
2. 키를 누르고 있으면 위쪽 상자에 `왼쪽 Ctrl  0:42 / 1:10` 처럼 시간이 표시됩니다.
   - 파랑: 누르는 중 → 노랑: 10초 남음 → 빨강: 시간 초과(알림)
3. 70초가 되면 알림음이 울리고, 손을 뗄 때까지 **5초마다** 다시 울립니다.

**게임 창을 눌러 놓은 상태에서 키를 눌렀는데 시간이 안 올라가면**, 아래쪽 **관리자 권한으로 다시 실행** 버튼을 누르세요.
메이플이 관리자 권한으로 돌아가서 일반 권한 프로그램에서는 키 상태가 안 보일 수 있습니다.

## 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| 알림 시간 | 70초 | 이 시간 이상 같은 키를 계속 누르면 알림. 실측상 공격은 약 75초(10젠)에 멈추므로 70초면 5초쯤 여유가 있습니다 |
| 손을 뗄 때까지 반복 | 켬, 5초마다 | 끄면 한 번만 울림 |
| 소리 크기 | 70% | **테스트** 버튼으로 미리 듣기. 실제 크기는 Windows 볼륨도 따릅니다 |
| 감시할 키 | 모든 키보드 키 | **아래 목록의 키만**을 고르고 **키 추가** → 공격 키(예: Ctrl)를 누르면 그 키만 감시. 이동 키를 오래 눌러도 울리지 않게 할 때 사용 |
| 항상 위에 표시 | 켬 | |

- 여러 키를 동시에 누르면 **키마다 따로** 시간을 잽니다. 위 상자에는 가장 오래 누른 키가 나옵니다.
- 왼쪽/오른쪽 Shift·Ctrl·Alt는 서로 다른 키로 봅니다.
- 마우스 버튼은 감시하지 않습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 아무 키도 안 눌렀는데 계속 어떤 키가 눌린 걸로 나옴 | 키보드 프로그램이 가상 키를 누르고 있는 경우입니다. **아래 목록의 키만**으로 바꿔 공격 키만 등록하세요 |
| 게임 중에만 시간이 안 올라감 | **관리자 권한으로 다시 실행** |
| 소리가 안 들림 | **테스트** 버튼 확인, Windows 볼륨 믹서에서 KeyHoldAlarm 음량 확인 |
| `build.bat` 에서 csc.exe를 못 찾음 | Windows 10/11에는 기본으로 있습니다. 없으면 'Windows 기능 켜기/끄기'에서 .NET Framework 4.8 을 켜세요 |
